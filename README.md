# Toy List

A React app for managing a toy collection, connected to a backend with full CRUD functionality.

![Screenshot of the Toy List app](./screenshot.png)

## Features
- View all toys on page load
- Add a new toy with the form
- Like a toy
- Donate (delete) a toy

## Installation
```bash
npm install
```

## Usage
Start the backend (check `package.json` for the exact script), then run:
```bash
npm run dev
```
Run tests with:
```bash
npm run test
```

## Technologies
React, Tailwind CSS, fetch API
